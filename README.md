# eBounce — Free Email Verification API

Get **10,000 free email verifications every month** — 100x the industry standard free tier.

- Syntax, MX, disposable & role-based checks via simple REST API
- Single + batch (up to 500) endpoints
- No credit card required

**Live:** https://ebounce.custmax.com · **Docs:** https://ebounce.custmax.com/docs

## Quick start

```bash
curl -H "X-API-Key: YOUR_KEY" "https://ebounce.custmax.com/api/check?email=test@example.com"
```

Get a free API key at https://ebounce.custmax.com/signup
