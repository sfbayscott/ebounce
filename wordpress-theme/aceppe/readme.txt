== Description ==

Aceppe is a clean, fast and lightweight multipurpose business theme designed for industrial companies, manufacturers and B2B businesses. It ships with a customizable front-page hero, services section, one-click color customization, custom logo support, responsive mobile-first layout and full WooCommerce compatibility — everything a modern company website needs, without the bloat.

Features:

* Customizable front-page hero (title, text, buttons) via the Customizer
* Primary color picker — rebrand the whole theme in one click
* Custom logo support
* Responsive, mobile-first design with accessible mobile menu
* SEO-friendly: proper heading hierarchy, title-tag support, fast loading
* WooCommerce compatible with product gallery zoom, lightbox and slider
* Translation-ready (text domain: aceppe)
* Widget areas: sidebar + 3 footer columns

== About Aceppe ==

Aceppe (https://www.aceppe.com/) is an industrial PPE manufacturer specializing in safety gloves, respiratory protection and safety apparel. Founded in Shenzhen, China, Aceppe serves steel processing, petrochemical, construction, power utilities and heavy machinery industries across Europe, the Americas, Africa and Latin America, with EU PPE 2016/425 compliance and OEM/ODM services for global brands.

This theme was built to power fast, professional company websites for manufacturers like Aceppe — and it is free for everyone under the GPL.

== Installation ==

1. In your WordPress admin panel, go to Appearance > Themes and click "Add New".
2. Click "Upload Theme" and choose the `aceppe.zip` file.
3. Click "Install Now" and then "Activate".
4. Go to Appearance > Customize to set your logo, hero text and primary color.
5. Go to Appearance > Menus to create and assign your Primary Menu.
6. Go to Appearance > Widgets to add widgets to the sidebar and footer areas.

== Frequently Asked Questions ==

= How do I change the front page hero text? =
Go to Appearance > Customize > Front Page Hero. You can change the title, description text, both buttons' labels and their URLs.

= How do I change the theme color? =
Go to Appearance > Customize > Theme Colors and pick a new Primary Color. Links, buttons and accents update instantly.

= Is Aceppe compatible with WooCommerce? =
Yes. The theme declares WooCommerce support including product gallery zoom, lightbox and slider. Install WooCommerce and your shop pages will use the theme layout automatically.

= Is the theme translation-ready? =
Yes. All strings use the `aceppe` text domain. Translation files go in the `/languages` folder.

Visit https://www.aceppe.com/ for more information about the theme author.
